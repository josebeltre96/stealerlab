# Reglas de detección

- `stealerlab.yar` — 12 reglas YARA organizadas en tres niveles (sample-specific, family-specific, behavioral).
- `sigma/` — 7 reglas Sigma con UUID válidos, validadas con sigma-cli 3.1.0.

Consulta los anexos B y C del TFM para el detalle y el fundamento de cada regla.

**Nota:** estas reglas son prototipos validados sintácticamente. No se ha medido su tasa de detección ni de falsos positivos en un SIEM de producción (ver sección 8.3 del TFM).
